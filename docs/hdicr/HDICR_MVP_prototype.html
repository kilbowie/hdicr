Frames

The bounded authority a human grants an agent — scope, spending caps, jurisdiction and expiry. Agents can act within a frame and narrow it, never widen it.

1 · Human verifiedpersonhood

3 · Registry issues HVA credentialdid:key
4 · Agent acts within framegate
5 · Every attempt loggedledger

There is no tool to create or widen a frame from the agent side — only the human grants.
